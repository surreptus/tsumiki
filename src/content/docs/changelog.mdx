Each page also shows when it was last updated. This list covers the changes a returning reader would want to know about.

## 28 October 2026

- Added a [Privacy and terms of use](/privacy-and-terms/) page.
- Added [Using this with a course](/overview/with-a-course/), on how to use the site beside a textbook.
- Added a "Report a mistake" link at the bottom of every page, and a link to the project on GitHub.
- The conjugator now dims suffixes that would be a type error as the next step, and Undo and Clear are the same size.
- The types illustration now shows each result's type under its block and uses たい, ない and た for the labels.
- Pages print in light colours with the controls left out.

## 27 October 2026

- First public version: the reference for every stem and suffix, the conjugator, the overview pages and seven guides (particles, sentence-ending particles, keigo, casual speech, clauses, conditionals, special expressions).
- ○ and × replace the check and cross marks.
- Repeated explanations were removed across pages, and the home page was rewritten around what the guide gives a learner.

Japanese on this site has not yet been reviewed by a native speaker. When corrections are made, they will be listed here.
